Add New Contacts for Newsletter

Installation and first-run guide

Install the application

1
Extract the downloaded ZIP

Open the ZIP and extract all its files into a regular folder before installing.

2
Run the installer

Double-click Install Newsletter App.cmd. It will bring up a terminal window.

3
Select the shared responses file

A File Explorer window will appear. Navigate to the UHS Newsletter Responses file you downloaded into your OneDrive folder. The app remembers this location for your Windows account.

4
Open the app

Double-click the new Add New Contacts for Newsletter app on your Home Desktop.

Running the Automation App

1
Prepare StarRez

Log into StarRez with Admin privileges and open the Main page.

2
Confirm the contact source

The shared responses CSV is selected by default. Use Choose file for a different CSV or Excel workbook, or Use shared responses to switch back.

3
Start the automation

Follow the instructions displayed in the app, then click the green START button.

Finished responses are remembered. A response is marked complete only after its StarRez automation succeeds. Failed, skipped, or cancelled responses remain pending.

Notifications

  • Windows checks the installer-selected shared responses CSV once per hour.
  • New pending responses trigger a Windows desktop notification.
  • The pending notification clears after all new responses are processed successfully.

Uninstall

To remove the desktop app and its hourly scheduled check, double-click Uninstall Newsletter App.cmd.

This guide works offline and may be reopened at any time.
